# ContreFinanças 💰

**Plataforma SaaS de gestão financeira pessoal com IA**

## 🎯 Módulos

1. **Gamificação** 🎮 - Sistema de pontos, badges e achievements
2. **IA Assistant** 🤖 - Chat inteligente com análise de gastos
3. **Relatórios Avançados** 📊 - Gráficos, previsões e insights
4. **Integração Bancária** 🏦 - Sincronizar contas reais

## 🏗️ Tech Stack

- **Frontend**: Vue 3 + Vite
- **Backend**: FastAPI + Uvicorn
- **Database**: Supabase (PostgreSQL)
- **Deploy**: Vercel + Railway
